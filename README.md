# 🎮 Minecraft Server by GitHub

**GitHub だけで Minecraft (Java版) のマルチプレイサーバーを動かす**リポジトリです。
レンタルサーバー・VPS・外部サービスへの登録は一切不要。必要なのは **GitHub アカウントと Minecraft 本体だけ**です。

## ✨ 特徴

- 🆓 **完全無料** — GitHub Actions 上でサーバーが動きます (パブリックリポジトリなら実行時間無制限)
- 🔌 **登録不要** — トンネルにアカウント不要の [bore.pub](https://github.com/ekzhang/bore) を使用
- 💾 **ワールド自動保存** — 定期 (既定20分ごと・変更可)・全員退出時・停止時に `world-data` ブランチへ自動バックアップ。次回起動時に自動復元
- 💤 **自動停止** — プレイヤーが30分いないと自動でシャットダウン (無駄な稼働なし)
- 🔄 **自動再起動** — GitHub の6時間制限に達したら、保存してから新しいサーバーを自動起動
- ⚙️ **かんたん設定** — `config/server.properties` を編集するだけ

## 🚀 サーバーの立て方 (3ステップ)

### ① このリポジトリを自分のアカウントにコピーする

右上の **Fork** ボタン (またはテンプレートなら **Use this template**) を押すだけ。

### ② Actions を有効にする

自分のリポジトリの **Actions** タブを開き、「I understand my workflows, go ahead and enable them」ボタンが表示されたら押して有効化します。

### ③ サーバーを起動する

1. **Actions** タブ → 左のリストから **🟢 Start Minecraft Server** を選択
2. **Run workflow** ボタンを押す (設定はそのままでOK) → もう一度緑の **Run workflow**
3. 開始された実行をクリックして数分待つと、**Summary (概要) ページにサーバーアドレスが大きく表示**されます

```
🎮 サーバーアドレス
bore.pub:12345
```

あとは Minecraft の **マルチプレイ → サーバーを追加** にこのアドレスを入力すれば遊べます! 🎉

## 🔴 サーバーの止め方

**Actions** タブ → **🔴 Stop Minecraft Server** → **Run workflow**

1〜2分以内にワールドを保存して安全に停止します。
(プレイヤーが30分間いない場合も、自動で保存して停止します)

## ⚙️ 設定

### 起動時のオプション (Run workflow を押したときに指定)

| オプション | 説明 | 初期値 |
| --- | --- | --- |
| Minecraftのバージョン | `latest` で最新版。`1.21.4` のように指定も可能 | `latest` |
| 無人時の自動停止 | プレイヤー不在で停止するまでの分数 (`0` で無効) | `30` |
| 自動バックアップの間隔 | ワールドを定期保存する間隔の分数 (`0` で定期保存を無効。全員退出時と停止時の保存は常に有効) | `20` |
| 自動再起動 | 6時間制限に達したとき自動で再起動するか | ON |

### サーバー設定 (`config/server.properties`)

難易度・ゲームモード・最大人数・MOTD などを変更できます。編集してコミットすると**次回起動時**に反映されます。

### 管理者権限 (`config/ops.txt`)

OP 権限を与えたいプレイヤー名を1行ずつ書いてコミットしてください。起動時に自動で付与されます。

## 💾 ワールドデータについて

- ワールドは **`world-data` ブランチ**に保存されます (定期バックアップ + 全員退出時 + 停止時)
- 次回起動時に自動で復元されるので、何もしなくてもワールドは引き継がれます
- ワールドをリセットしたい場合は `world-data` ブランチを削除してから起動してください

## ❓ よくある質問

**Q. アドレスが毎回変わるのはなぜ?**
A. 無料・登録不要のトンネルを使っているため、起動ごとにポート番号が変わります。最新のアドレスは Actions の最新の実行の Summary で確認できます (`world-data` ブランチの `SERVER_ADDRESS.txt` にも書き込まれます)。

**Q. 何時間遊べる?**
A. GitHub Actions の1回の実行上限が6時間のため、約5.5時間で自動保存・自動再起動します (再起動後はアドレスが変わるので再接続してください)。

**Q. 統合版 (スマホ/Switch/PS) から遊べる?**
A. このサーバーは **Java版専用**です。

**Q. プライベートリポジトリでも使える?**
A. 使えますが、無料枠は月2,000分 (約33時間) までです。**パブリックリポジトリなら無制限**ですが、ワールドデータも公開される点に注意してください。

**Q. 重い・カクつく**
A. `config/server.properties` の `view-distance` を `8` 程度に下げてみてください。無料ランナーの性能上、快適に遊べるのは数人程度です。

## ⚠️ 注意事項

- GitHub Actions は本来 CI/CD (ソフトウェアのビルドやテスト) のためのサービスです。ゲームサーバーの常時稼働は [GitHub の利用規約](https://docs.github.com/site-policy/github-terms/github-terms-for-additional-products-and-features#actions) に抵触する可能性があります。**自己責任で、節度を持って利用してください** (無人時の自動停止は必ず有効のままにすることを推奨します)。
- Minecraft サーバーの利用には [Minecraft EULA](https://www.minecraft.net/eula) への同意が必要です。サーバー起動時に自動で同意した扱いになります。

```
              GitHub Actions ランナー

```
